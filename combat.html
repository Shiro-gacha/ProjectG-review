Inspect the character pixel scale.

Generated source images are larger originals. This canvas crops each visible subject, samples it onto an intermediate grid and displays that grid at 1× with nearest-neighbor rendering. Each character grid is twice as tall and twice as wide as the first pass, with the same on-stage height. The originals remain unchanged high-resolution images, rather than native 192px source art.

Heroes: 192px tall → 192px on stage. Seraxis: 224px → 224px (Boss Focus and combined layout: 256px → 256px). Velkara: 200px → 200px. Scorpion: 128px → 128px. The background is sampled to 640 × 360, then displayed at 2×. UI text is drawn at the 1280 × 720 screen resolution.
